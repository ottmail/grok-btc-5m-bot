# Grok BTC 5m Sniper Bot

24/7 automated trading bot for Polymarket Bitcoin Up/Down 5-minute markets.

**Features**
- Telegram control (/start, /stop, /status)
- Real-time price action + TA strategy
- Dry-run mode for safe testing
- Self-correcting & 24/7 monitoring

**Setup**
- Fill secrets in GitHub or Railway Variables
- Start in DRY_RUN=True first
